# Aira - React Chatbot

Aira is a simple chatbot interface built using React, JavaScript, and CSS. It provides a clean and user-friendly chat interface where users can interact with a chatbot and receive responses to common messages.

## Features

- Interactive chat interface
- Rule-based chatbot responses
- Responsive and clean UI
- Built with React functional components and hooks
- Simple and beginner-friendly project structure

## Tech Stack

- React
- JavaScript
- HTML5
- CSS3
- Vite

## Getting Started

Follow these steps to run the project locally.

### Prerequisites

- Node.js
- npm

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/Rashikumari18/Aira-chatbot.git
   ```

2. Navigate to the project folder:

   ```bash
   cd Aira-chatbot
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the local URL shown in your terminal.

## Build for Production

To create a production build, run:

```bash
npm run build
```

To preview the production build locally, run:

```bash
npm run preview
```
